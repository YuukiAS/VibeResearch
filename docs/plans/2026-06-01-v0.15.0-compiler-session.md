# VibeResearch 0.15.0 Compiler Session Plan

## Purpose

This plan implements `docs/todos/TODO-v20.md`. 0.15.0 adds a Compiler Session
that turns an accepted `reviewed_plan_manifest.json` into an auditable execution
contract. Planner and Reviewer own research logic; Compiler owns translation to
paths, commands, expected artifacts, resource intent, evaluation command, stop
condition, fallback command, and safety checks.

## Scope

0.15.0 will add:

- An `execution_manifest.json` schema with accepted plan id, review approval id,
  repo paths, input assets, commands, resource plan, expected artifacts,
  evaluation commands, stop conditions, fallbacks, artifact inventory, and
  safety checks.
- Compiler validation that refuses missing or non-`ACCEPT` review approvals.
- Translation from reviewed plan mechanism/MVE fields into concrete local paths,
  script draft, optional Slurm draft, expected artifact path, and metric reader.
- Preservation of Reviewer criteria, required changes, blocking risks, and
  approval trace in the execution manifest.
- CLI commands for compiling and validating execution manifests.

## Commands

Add:

- `vibe compiler compile`
- `vibe compiler validate`

## Gates

- A plan without accepted review approval cannot compile.
- Missing concrete artifact paths, metric reader, stop condition, or fallback
  command fails compilation or validation.
- Compiler must not compile rejected, revise, or ask-human reviews.
- Reviewer constraints must be copied into the execution manifest.

## Tests

Add tests for:

- no review approval cannot compile;
- missing concrete artifact path or metric reader fails;
- Reviewer constraints are preserved;
- compiled execution manifest passes the boundary guard.

## Commit Criteria

Before committing 0.15.0:

- update version metadata, `CHANGELOG.md`, and README docs as needed;
- run targeted Compiler tests;
- run full pytest;
- stage only 0.15.0 files and commit.
