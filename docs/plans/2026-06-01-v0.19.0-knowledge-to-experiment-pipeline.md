# VibeResearch 0.19.0 Plan: Knowledge-to-Experiment Pipeline

Source TODO: `docs/todos/TODO-v29.md`

## Purpose

Route papers, repositories, deep research notes, and user ideas through a
mechanism-card gate before they can influence execution. Knowledge must become a
mechanism, then a Planner draft, then a reviewed Compiler manifest.

## Scope

- Define `mechanism_card.md` with source, claim, mechanism extraction, why it
  matters, failure anchor, possible MVE, required assets, risks, and stop reason.
- Ensure Scout outputs mechanism cards only and never writes execution manifests.
- Archive mechanism cards that lack a possible MVE.
- Let Planner create a complete draft plan from a valid mechanism card while
  filling hypothesis, expected belief update, artifact, and fallback fields.
- Let Compiler preserve mechanism-card path and dependencies in manifests while
  rejecting clone/install-only goals as experiments.
- Keep the implementation framework-generic and avoid CARE execution.

## Files

- `vibe_research/scout.py`: mechanism-card schema, writer, registry, validation,
  and archive status.
- `vibe_research/planner.py`: draft generation from valid mechanism cards.
- `vibe_research/compiler.py`: mechanism-card input assets and clone/install
  target guard.
- `vibe_research/cli.py`: Scout and Planner commands for the card pipeline.
- `tests/test_knowledge_pipeline.py`: TODO-v29 coverage.
- `CHANGELOG.md`, `README.md`, `docs/README_CN.md`, and version metadata.
