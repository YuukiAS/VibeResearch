# VibeResearch 0.15.1 MVE Contract Plan

## Purpose

This plan implements `docs/todos/TODO-v21.md`. 0.15.1 adds a minimum viable
experiment contract to every execution package so plans cannot jump directly
from idea to large training, 5-fold runs, hosted validation, or packaging.

## Scope

0.15.1 will add:

- MVE levels for foundation ideas, component verifiers, Cine/hybrid routes, and
  training routes.
- Required MVE fields: input asset, minimal command, expected artifact,
  metric/evidence reader, success condition, failure condition, cost cap, and
  next promotion rule.
- Compiler integration so `execution_manifest.json` includes an `mve_contract`.
- Validation that blocks execution manifests with missing MVE contracts or
  missing MVE artifacts.
- Promotion-debt helpers so one-case success produces subset debt, subset
  produces fold0 debt, and MVE success cannot declare the main line complete.

## Commands

Add:

- `vibe mve validate`
- `vibe mve promote-success`

## Gates

- Execution manifests without an MVE contract are invalid unless a human MVE
  exception is explicitly recorded.
- Big training, 5-fold, hosted validation, and packaging require prior MVE or
  human approval.
- MVE artifact absence blocks completion.
- MVE success generates the next evidence debt instead of mainline success.

## Tests

Add tests for:

- no MVE execution manifest is rejected;
- one-case success generates subset debt;
- large training requires MVE or human approval;
- missing MVE artifact cannot close execution.

## Commit Criteria

Before committing 0.15.1:

- update version metadata, `CHANGELOG.md`, and README docs as needed;
- run targeted MVE/Compiler tests;
- run full pytest;
- stage only 0.15.1 files and commit.
