# VibeResearch 0.16.0 Executor Session Plan

## Purpose

This plan implements `docs/todos/TODO-v22.md`. 0.16.0 adds a bounded Executor
Session that runs only accepted `execution_manifest.json` contracts. Executor
may run commands, write logs, collect artifacts, and report blockers, but it
must not redefine failure anchors, hypotheses, mechanisms, or promotion
criteria.

## Scope

0.16.0 will add:

- Manifest-driven execution helpers that refuse missing or invalid execution
  manifests.
- Execution logs, artifact inventory updates, and result reports under
  `.vibe/executor/`.
- Boundary checks that preserve reviewed scientific fields and reject Executor
  attempts to change scientific goals.
- Completion criteria that require expected artifacts or an explicit blocker
  report; smoke/readiness alone cannot close execution.
- Provenance capture for commands, stdout/stderr, environment, input assets,
  output paths, job id placeholders, and failure handling.

## Commands

Add:

- `vibe executor run`
- `vibe executor validate-result`

## Gates

- Executor refuses to run without an accepted execution manifest.
- Executor cannot mutate failure anchor, hypothesis, mechanism, or promotion
  criteria.
- Missing expected artifacts produce a blocker report, not completion.
- Result reports must be readable by the future Reflector.

## Tests

Add tests for:

- missing manifest is rejected;
- scientific-field mutation is rejected;
- missing expected artifact prevents completion and writes blocker report;
- successful execution writes artifact inventory, execution log, and result
  report with provenance.

## Commit Criteria

Before committing 0.16.0:

- update version metadata, `CHANGELOG.md`, and README docs as needed;
- run targeted Executor tests;
- run full pytest;
- stage only 0.16.0 files and commit.
