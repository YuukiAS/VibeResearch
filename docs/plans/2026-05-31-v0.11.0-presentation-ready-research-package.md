# VibeResearch 0.11.0 Presentation-Ready Research Package Plan

## Purpose

This plan implements `docs/todos/TODO-v12.md`. VibeResearch should turn a long
research history into a reproducible, auditable narrative package: not slides,
but the structured evidence, tables, framework spec, and negative-result record
that a downstream project can use to prepare a final presentation or report.

The implementation must remain generic and project-agnostic.

## Scope

0.11.0 will add:

- A framework narrative registry that separates background, external baseline,
  failed exploration, key insights, owned modules, evidence, limitations, and
  future work.
- A reproducibility package linking conclusions to experiments, runs, metrics
  files, artifacts, adapter revisions, policy revisions, code commits, and
  memo evidence.
- Figure/table data exports for baseline comparisons, ablations, stage-gate
  progression, budget usage, hypothesis outcomes, scout-to-experiment traces,
  and external-to-owned transition timelines.
- A final framework spec covering modules, interfaces, data flow,
  train/infer/eval paths, dependencies, owned-core boundaries, and optional
  external regression components.
- Negative-result retention so stopped or harmful directions remain visible
  rather than being filtered out of the final narrative.

## Commands

Add generic CLI surfaces under `vibe present`:

- `vibe present narrative`
- `vibe present reproducibility`
- `vibe present tables`
- `vibe present framework-spec`
- `vibe present package`

All commands should be deterministic, local, and file-backed.

## Gates

- Claims without traceable evidence must be excluded from the final narrative
  and listed as speculation or future work.
- Table rows must retain source IDs and artifact paths.
- Framework specs must align with active adapter/internal capabilities and owned
  scaffold records when present.
- Negative results and protected-metric failures must remain in the package.

## Tests

Add tests for:

- untraceable claims excluded from narrative;
- reproducibility package records experiment/run/metrics/artifact/provenance;
- figure/table export contains traceable rows;
- owned framework spec aligns with active capability metadata;
- negative results are preserved;
- external-to-owned transition timeline is generated.

## Commit Criteria

Before committing 0.11.0:

- update version metadata and `CHANGELOG.md`;
- run targeted presentation tests;
- run full pytest;
- stage only 0.11.0 files and commit.
