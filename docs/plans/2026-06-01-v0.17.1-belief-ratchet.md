# VibeResearch 0.17.1 Plan: Belief Ratchet

Source TODO: `docs/todos/TODO-v26.md`

## Purpose

Add a Belief Ratchet so Reflector outputs update layered research memory instead
of collapsing results into a simple success/failure label. The framework should
preserve feasibility, mechanism, metric, robustness, and negative evidence as
different kinds of belief changes.

## Scope

- Define evidence types: feasibility, mechanism, metric, robustness, and
  negative evidence.
- Convert Reflector manifests into ratchet records with accepted plan,
  execution manifest, artifact pointer, metric vector, evidence type, belief
  delta, and next debt.
- Update Problem Memory, Mechanism Memory, Experiment Memory, Negative Memory,
  and Open Debt Memory according to evidence type.
- Preserve mechanism evidence even when a final metric does not improve.
- Prevent one-case evidence from being promoted to robustness belief.
- Add CLI commands to apply and validate ratchet records.
- Keep implementation generic and framework-level; do not run CARE rounds.

## Files

- `vibe_research/belief_ratchet.py`: ratchet record creation, validation, and
  memory updates.
- `vibe_research/cli.py`: `vibe ratchet apply` and validation commands.
- `tests/test_belief_ratchet.py`: coverage required by TODO-v26.
- `CHANGELOG.md`, `README.md`, `docs/README_CN.md`, and version metadata.
