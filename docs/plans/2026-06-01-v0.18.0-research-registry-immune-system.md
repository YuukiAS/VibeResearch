# VibeResearch 0.18.0 Plan: Research Registry and Immune System

Source TODO: `docs/todos/TODO-v27.md`

## Purpose

Add a generic research registry and immune system so failed or low-value routes
become hard planning/review context. The framework should block renamed repeats
unless the new plan has a new mechanism, information source, artifact, or
evidence path.

## Scope

- Define route fingerprints from failure anchor, mechanism, base model, data
  split, action type, artifact type, metric vector, review verdict, reflect
  decision, and evidence type.
- Record plan, review, execution, result, reflect, ratchet, budget checkpoint,
  resume, and low-quota interruption events.
- Generate failure antigens from STOP, guardrail regression, adapter impossible,
  orphan knowledge, metadata-only loops, and similar blocked routes.
- Expose registry/immune checks for Planner and Reviewer.
- Planner must mark repeated historical routes before draft execution.
- Reviewer must reject highly similar repeats when no novelty is present.
- Keep implementation generic and framework-level; do not run CARE rounds.

## Files

- `vibe_research/immune_registry.py`: fingerprints, registry events, antigens,
  similarity checks, and recovery lookup.
- `vibe_research/planner.py`: registry-aware draft diagnostics.
- `vibe_research/reviewer.py`: registry-aware repeat rejection.
- `vibe_research/cli.py`: `vibe registry ...` commands.
- `tests/test_immune_registry.py`: coverage required by TODO-v27.
- `CHANGELOG.md`, `README.md`, `docs/README_CN.md`, and version metadata.
