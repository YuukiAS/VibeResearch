# v0.20.3 Living Brief and Human Guidance

## Source prompt

- `prompts/v0.19.0-gpt_manual_prompt.md`

## Scope

Add backend file protocols and minimal integration for:

- Living Research Brief / Persistent Research Situation Brief.
- Human Idea Inbox / User Guidance Inbox.

This is not a frontend release and does not run downstream experiments.

## Requirements

- Generate `.vibe/research/CURRENT_RESEARCH_BRIEF.zh.md`,
  `.vibe/research/CURRENT_RESEARCH_BRIEF.en.md`, and
  `.vibe/research/research_brief.json`.
- Support `research.brief_language: zh|en`.
- Ground the brief in project state, failure signatures, evidence ledger,
  negative memory, open debts, real-experiment progress, human guidance, and
  unconsumed mechanism cards.
- Create `.vibe/research/human_guidance.jsonl` and
  `.vibe/research/HUMAN_IDEA_INBOX.md`.
- Store timestamp, source, raw text, language, priority, linked failure
  signature, suggested mechanism, status, review decision, applied plan,
  supersession, and notes for each guidance item.
- Let `vibe idea` also enter the human guidance inbox.
- Let Planner expose absorbed/unapplied guidance and warn on unaddressed active
  guidance.
- Let Reviewer require active guidance to be absorbed or explicitly explained.
- Let Reflector update partially applied guidance after evidence is observed.
- Add `vibe guidance ...` and `vibe brief ...` commands.

## Validation

- Add unit/CLI tests for guidance ingestion, brief files, Planner/Reviewer
  gates, and CLI commands.
- Run the full pytest suite before release commit.
