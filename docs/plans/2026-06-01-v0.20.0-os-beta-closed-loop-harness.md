# VibeResearch 0.20.0 Plan: OS Beta Closed-Loop Harness

Source TODO: `docs/todos/TODO-v31.md`

## Purpose

Add a framework-level closed-loop harness that proves the multi-session file
protocol can advance a research round without letting invalid actions masquerade
as progress. This is a generic integration harness, not a CARE execution.

## Scope

- Run a complete Planner -> Reviewer -> Compiler -> Executor -> Reflector ->
  Registry -> Ratchet -> next Planner loop on a toy MVE.
- Verify draft plan, review report, reviewed manifest, execution manifest,
  result report, reflect report, registry update, and memory update.
- Call Budget-Aware Session Runtime guards for each closed-loop phase.
- Check role isolation and review-before-execute / manifest-driven execution
  invariants.
- Exercise registry blocking, decision debt clearing, and low-quota checkpoint
  behavior in harness diagnostics.
- Expose the harness through CLI without running CARE rounds.
