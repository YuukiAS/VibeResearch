# VibeResearch 0.18.1 Plan: Decision Debt TTL

Source TODO: `docs/todos/TODO-v28.md`

## Purpose

Make WATCH/REFINE outcomes bounded research debt instead of a holding state.
Every open decision debt must state what evidence is missing, how it will be
repaid, and when it expires into STOP or PIVOT.

## Scope

- Define a structured decision debt record with source reflect id, watched
  mechanism, current evidence, missing evidence, repayment MVE, TTL, promotion
  condition, pivot condition, stop condition, and owner session.
- Bind Reflector REFINE/WATCH-style next actions to open debt records and reject
  WATCH/REFINE records without a repayment MVE.
- Have Planner read open structured debts and mark plans that ignore them.
- Implement TTL clearing so two uncleared rounds close debt into STOP or PIVOT.
- Write STOP clearances to negative memory, PIVOT clearances to plan seeds, and
  all clearances to the Research Registry.
- Keep the work generic; do not run CARE rounds.

## Files

- `vibe_research/decision_debt.py`: debt schema, validation, open-debt state,
  TTL clearing, registry handoff, and plan seed/negative memory writes.
- `vibe_research/reflector.py`: require and write debt records for REFINE/WATCH
  outcomes.
- `vibe_research/planner.py`: structured debt priority diagnostics.
- `vibe_research/cli.py`: debt listing, validation, and clearing commands.
- `tests/test_decision_debt.py`: TODO-v28 coverage.
- `CHANGELOG.md`, `README.md`, `docs/README_CN.md`, and version metadata.
