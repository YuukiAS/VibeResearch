# VibeResearch 0.11.1 Final Convergence Policy Plan

## Purpose

This plan implements `docs/todos/TODO-v13.md`. VibeResearch needs a generic
policy for moving from open exploration to final owned-framework convergence
without either exploring forever or cutting off external baselines too early.

## Scope

0.11.1 will add:

- Convergence stages: `open_exploration`, `dual_track_optimization`,
  `owned_candidate_focus`, `external_regression_only`, and
  `final_owned_freeze`.
- Freeze rules requiring trusted evidence, protected-metric stability,
  reproducibility package readiness, budget closure, known-risk review, and
  user approval.
- Late-stage risk gates that block or ask the user before core mechanism
  changes, protected-metric risks, reproducibility-breaking changes, or large
  external-method additions.
- Final external dependency audit with necessary, reference, regression, and
  removal-candidate dependency classifications.
- Override records for user-approved exceptions.

## Commands

Add generic CLI surfaces under `vibe converge`:

- `vibe converge stage`
- `vibe converge freeze-check`
- `vibe converge risk-gate`
- `vibe converge dependency-audit`
- `vibe converge override`

## Gates

- Freeze is blocked without all required evidence and user approval.
- After freeze, large new external directions and core rewrites are blocked
  unless an explicit override is recorded.
- Late-stage protected metric risk blocks by default.
- Owned-framework claims require external dependency audit evidence that the
  main path is sufficiently owned.

## Tests

Add tests for:

- freeze blocked without trusted evidence or reproducibility package;
- freeze accepted only with all gates and approval;
- freeze blocks large new external directions;
- override records unblock an otherwise blocked action;
- dependency audit classifies final dependencies;
- late-stage protected metric risk blocks.

## Commit Criteria

Before committing 0.11.1:

- update version metadata and `CHANGELOG.md`;
- run targeted convergence tests;
- run full pytest;
- stage only 0.11.1 files and commit.
