# VibeResearch 0.17.0 Plan: Reflector Session

Source TODO: `docs/todos/TODO-v25.md`

## Purpose

Add an independent Reflector Session that interprets Executor outputs after
execution. Reflector must read real artifacts and provenance, produce
`reflect_report.md`, and decide a bounded next action without letting Executor
declare research success.

## Scope

- Add a Reflector framework module with verdicts `PROCEED`, `REFINE`, `PIVOT`,
  `STOP`, and `ASK_HUMAN`.
- Require evidence, metric, guardrail, and belief update fields in every
  reflection.
- Read Executor result manifests, artifact inventory, expected artifacts,
  metrics JSON, case-level failure artifacts when present, and execution logs.
- Treat smoke/import-only success as feasibility evidence, not research
  success.
- Convert MVE success into promotion debt rather than mainline success.
- Reject or downgrade results with missing artifacts, untrusted metrics, subset
  failure, or guardrail regression.
- Call the 0.16.2 session budget guard before reflection and write partial
  reflect plus `RESUME.md` when quota is too low.
- Keep implementation generic and framework-level; do not execute any CARE
  round or project-specific experiment.

## Files

- `vibe_research/reflector.py`: reflection validation, report rendering, and
  registry updates.
- `vibe_research/cli.py`: `vibe reflector reflect` and validation commands.
- `tests/test_reflector.py`: coverage required by TODO-v25.
