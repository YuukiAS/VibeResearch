# VibeResearch 0.16.2 Plan: Budget-Aware Session Runtime

Source TODO: `docs/todos/TODO-v24.md`

## Purpose

Move session budget awareness from protocol text into framework state and CLI
checks. Every role should have a shared `SESSION_BUDGET_STATE.json`, a guard
decision for PLAN/REVIEW/COMPILE/EXECUTE/REFLECT/SLEEP, and a checkpoint/resume
path when quota is low.

## Scope

- Add a generic budget runtime module for `SESSION_BUDGET_STATE.json`.
- Support manual quota refresh from observed `codex --no-alt-screen` `/status`
  text, including 5h and weekly percentage parsing.
- Add action decisions for `PLAN`, `REVIEW`, `COMPILE`, `EXECUTE`, `REFLECT`,
  and `SLEEP`, using the existing session role priority rules.
- Generate low-budget checkpoints and root `RESUME.md` when quota is below 10%.
- Add zero-cost wait records that distinguish Slurm job waits from quota waits.
- Add a `wait_until_budget_reset.sh` helper template for quota wait mode.
- Keep this generic and local to VibeResearch; do not launch Codex, Slurm, or
  CARE-specific execution.

## Files

- `vibe_research/session_budget.py`: budget state, guard, checkpoint, resume,
  and wait helper logic.
- `vibe_research/cli.py`: `vibe budget-runtime ...` commands.
- `tests/test_session_budget.py`: state, parsing, guard, checkpoint, wait mode,
  and resume tests.
- `CHANGELOG.md`, `README.md`, `docs/README_CN.md`, and version metadata.
